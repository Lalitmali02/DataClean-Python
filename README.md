# DataClean-Python 🐍

A beginner-friendly Python project that checks datasets for common data quality problems.

## About

DataClean is a simple Python-based data quality checker. It allows users to enter their own dataset and generates a report showing missing values and duplicate records.

This project was created as my first Python project to practice programming fundamentals and basic data processing.

## Features

- Take dataset input from the user
- Create custom columns
- Add multiple records
- Count total records and columns
- Detect missing values
- Detect duplicate records
- Remove duplicate records
- Generate a data quality report

## Technology Used

- Python

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python main.py

6. Enter the dataset information when asked.
